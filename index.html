How to connect AIS on phone

Cloud relay is already built in. You mainly need a free AISStream API key.

  1. Get a free key at aisstream.io (GitHub login).
  2. Open ⚙ Settings, paste the key into AISStream API key, tap Save.
  3. Live ships use the default relay boatboard-ais.aisrelay.workers.dev — no Pi or laptop to leave on.
  4. Optional: override the relay URL in Settings if you run your own Worker.

AISStream blocks browsers directly; GitHub Pages is static. Cached ships still show if the feed drops.
